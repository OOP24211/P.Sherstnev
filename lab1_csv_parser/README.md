CSV:
Программа для подсчета частоты слов в текстовом файле.
Функционал:
- Обработка слов с дефисами (`что-то`) и апострофами (`don't`).
- Сортировка: сначала по количеству (убывание), затем по алфавиту.
- Вывод в формате CSV.
Запуск:
1. Положите текст в `in.txt`.
2. Запустите `Main.java`.
3. Результат будет в `report.csv`.
